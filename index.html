プライバシーポリシー（それ持ってるし）

制定日: 2026年10月23日

運営者: 田中北斗

お問い合わせ: troncenter@gmail.com

田中北斗（以下「運営者」）は、iPhone アプリ「それ持ってるし」（以下「本アプリ」）での情報の取り扱いを、次のとおり定めます。

1. 基本方針

本アプリは、アカウント登録なしで使えます。運営者は、利用者の氏名・メールアドレス・位置情報・端末の広告IDなどの個人情報を集めません。運営者が管理するサーバーもありません。

2. 本アプリが扱う情報と、その行き先

情報使い方送り先・保存場所
カメラで撮った写真・写真ライブラリから選んだ写真本棚の背表紙から作品名と巻数を読み取るため端末の中だけで処理します。写真を外部に送ったり、本アプリ内に保存したりしません
読み取った作品名・著者名の文字正式な作品名に直すため（設定でオフにできます）Apple の書籍検索（iTunes Search API）と国立国会図書館サーチの検索 API に、検索のために送ります。写真は送りません。検索結果は端末の中に最大7日間保存します
登録した作品名・巻数などの本棚データ本棚の記録と、同じ Apple アカウントの端末どうしの同期のため端末の中と、利用者自身の iCloud（Apple の CloudKit のプライベート領域）に保存します。運営者は見ることができません
設定の内容アプリの動作のため端末の中に保存します

各送り先での情報の取り扱いは、それぞれの方針に従います。

  • Apple のプライバシーポリシー: https://www.apple.com/jp/legal/privacy/
  • 国立国会図書館サーチ: https://ndlsearch.ndl.go.jp/ （利用規約・プライバシーポリシーを参照）

3. 購入リンク（アフィリエイト）について

本アプリは、作品の画面に「次の巻を探す」リンクを表示します（設定でいつでも非表示にできます）。リンクを押すと、Amazon または楽天ブックスの検索結果を Safari などの外部ブラウザ で開きます。

  • 当アプリはアフィリエイトプログラムを利用しています。リンク先で商品を購入されると、運営者が紹介料を受け取ることがあります（商品の価格は変わりません）。
  • リンク先のサイトでは、Amazon・楽天などがクッキー等を使って情報を取得することがあります。その取り扱いは各社のプライバシーポリシーに従います。本アプリ自身は、リンクを押したかどうかなどの情報を集めません。
  • Amazon.co.jp プライバシー規約: https://www.amazon.co.jp/gp/help/customer/display.html?nodeId=GX7NJQ4ZB8MHFRNJ
  • 楽天グループ 個人情報保護方針: https://corp.rakuten.co.jp/privacy/

4. 分析・広告・トラッキング

本アプリは、利用状況の分析ツール、広告配信ツール、クラッシュ情報を集めるツールを組み込んでいません。他社のアプリやWebサイトの情報と組み合わせて利用者を追跡すること（トラッキング）もしません。

5. 第三者への提供

運営者は利用者の個人情報を持たないため、第三者に提供することはありません。上の2・3に書いた送り先（Apple、国立国会図書館、利用者がリンクを押したときの Amazon・楽天）を除き、本アプリから外部に情報が送られることはありません。

6. お子さまの利用

本アプリは、保護者がお子さまの本を管理することを想定しています。お子さまから個人情報を集めることはありません。

7. データの削除

本棚データは、本アプリで作品を削除するか、本アプリを削除すると端末から消えます。iCloud に保存されたデータは、iPhone の「設定」→［利用者の名前］→「iCloud」→「ストレージを管理」（表示名は iOS のバージョンにより異なります）から削除できます。

8. このポリシーの変更

内容を変更するときは、このページを更新し、変更日を記載します。大きな変更は本アプリまたはこのページでお知らせします。
